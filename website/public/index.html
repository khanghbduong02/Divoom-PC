From download to display

Running in a few minutes.

No installer, no account, and no Python on the target PC. The sensor helper is bundled inside the app.

  1. 01

    Download and run

    Put GateThemeStudio.exe anywhere and double-click it. The editor opens in your browser and a tray icon appears.

  2. 02

    Add CPU temperature

    On first run, accept the optional sensor helper. It needs one Windows administrator approval and starts automatically from then on.

  3. 03

    Connect the Gate

    Use the connection wizard while the display and PC are on the same Wi-Fi. Enter the IP manually if automatic discovery does not find it.

  4. 04

    Make it yours

    Add metrics, labels, bars and graphs, or start from a built-in theme. Press Apply for one screen or Send all for every edited panel.

Local by design

This is a download page,
not a hosted dashboard.

The editor is served by the app on your own PC. That is deliberate: a public website cannot read your computer’s sensors or reach a device inside your home network.

Your readings, display connection and designs stay on your machine. Open the editor on your phone by joining the same Wi-Fi, if you want to.

No account No app telemetry LAN-only by default

The details

Made for a five-screen display.

▦

Five-panel editor

Move, resize, layer and reorder anything on any screen. Empty panels stay empty.

↗

Live readings

CPU, GPU, memory, disk, network and fan values keep refreshing while the app runs.

◫

Bars and graphs

Show a number, a progress bar or a history graph from the last 5 minutes to 3 hours.

✳

Themes and saves

Start from a built-in look or keep named versions of a full theme or a single panel.

⇄

Divoom-app hand-off

Screens changed from the phone app are paused automatically so the two do not fight.

◷

Tray and autostart

Close the tab and the display keeps updating. Start with Windows when you want it.
